# ForwardDesk landing page

Static marketing page for ForwardDesk, published with GitHub Pages at https://aibit.github.io/forwarddesk-site/.

- Live demo: https://aibit.github.io/forwarddesk/
- Promo video: `assets/forwarddesk-promo.mp4` (16:9) and `assets/forwarddesk-promo-vertical.mp4` (9:16)
- Waiting list: see WAITLIST.md. The form stays in honest fallback until `config.js` is set.

The page covers the agent CRM, job documents, billing and finance, plus a choice between the live demo and joining the waitlist for a real account.

All screens show sample data only.
